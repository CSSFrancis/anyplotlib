``linestyle="none"`` (also spelled ``"None"``) draws a series' markers with no
connecting line — matplotlib's scatter idiom, ``ax.plot(y, linestyle="none",
marker="o")``.  An explicit ``linewidth=0`` now means the same thing; it
previously fell back to the 1.5 default in the renderer.  Both apply to the
primary line and to :meth:`~anyplotlib.Plot1D.add_line` overlays, and the
legend swatch drops its rule to match.
