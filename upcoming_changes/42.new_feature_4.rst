New 2-D overlay widget kinds:

* ``line`` (:meth:`~anyplotlib.Plot2D.add_line_widget`) — a bare two-endpoint
  segment with a grab handle at each end.  Drag an endpoint to move that end
  or the shaft to translate the whole segment.  ``arrow`` draws a head and
  ``polygon`` requires >= 3 vertices and closes the path, so neither could
  stand in for a line profile, a cross-section cut, or a two-point
  measurement.  ``widget.length`` reports the segment length.
* ``vline`` / ``hline`` (:meth:`~anyplotlib.Plot2D.add_vline_widget`,
  :meth:`~anyplotlib.Plot2D.add_hline_widget`) — full-height / full-width
  rules, grabbable anywhere along their length.  These existed on 1-D panels
  only, so a 2-D panel had to fake a single-axis pointer with a ``crosshair``,
  which leaves a stray perpendicular rule across the image.
